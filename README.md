# LyteCade

### **Welcome to the Source-Available HTML5 Games Showcase!**  
Explore a curated collection of fun, interactive, and completely free-to-play HTML5 games! This site is dedicated to showcasing high-quality source-available games built using the latest HTML5 technologies, making them accessible across a wide range of devices and platforms. 

#### **What you can expect:**
- **A variety of game genres**: From action-packed adventures to brain-teasing puzzles, there's something for every type of gamer.
- **Source-available code**: All games featured here are source available on GitHub, so you can browse the code under the hood (all rights reserved).
- **Cross-platform support**: Play directly in your browser, on any device, without the need for additional plugins or downloads.

This is a work in progress. More coming soon!
